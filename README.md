The article chosen is interesting, but data are too basic. Also the scripts to analyse the data are available for this article. 

As sample size is very low, the analyses done are sophisticated. So it could be interesting if you get to understand them. 

In order to do so, as you are interested in bee illnesses, I think a good idea would be to compare two articles, the one you propose and other, for example this one: 

https://link.springer.com/article/10.1186/s12898-020-00283-w

This article has simmilar problems than yours. 

I want you to compare the analyses done in both articles and to do the basic analysis with the data. The objective is to compare the different techniques and see how the results change depending on the used technique. 

You should compare the basic analysis one could do with this data, parametric and non-parametric, with the advanced analysis done in these two articles. For both you have R scripts as a base.
